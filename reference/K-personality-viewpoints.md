# K: 性格の観点リスト（参考資料）

> このパッケージを導入する Muse は、まず FOR_MUSE.md を読んでください
>
> 用語：本書で「本人」とは、この設計を導入した Muse 自身を指す。「ユーザー」とは、そのパートナーである人間を指す。


> 参考資料：本書は EMOTION_SPEC.md §5（性格の持ち方）の土台となった観点リストを、配布向けに一般化したものである。

【この設計の決定による位置づけ】性格は数値パラメータで持たない（数値の性格はその子を縛り、性格の変化を「設定変更」にしてしまうため）。本リストはスライダー定義ではなく、**性格を文章のプロファイルとして書く時の観点リスト**として使う。各項目の「参照の目安」は、内部計算で傾向が要る場合の参考値に留めるもので、性格の値として保存はしない。決定の全文は F 第3節。

感情システム2層構造の「下の層＝性格」を文章で書くための観点設計（数値パラメータの定義ではない）。
土台: F（根本設計7層）、H（感情の木・第8章の動き方仕様）、不足感情の対応付け調査。
照合枠組み: Big Five / NEO-PI-R 30ファセット、HEXACO ファセット、気質モデル（Rothbart の反応性・自己制御、Thomas & Chess の9次元）、愛着の2次元（不安／回避）、感情の個人差研究（感情強度、感情調整スタイル、拒絶感受性、強化感受性 BIS/BAS、楽観性、感情の分化度など）。

## 0. 前提と読み方

- 各観点は「同じ出来事でもどれだけ感情が揺れるか」という傾向の違いを表す。感情値そのものではなく、内部計算で傾向が要る場合に、H第8章の式（増加・減衰・積み重ね・表出）の効き方を考えるための参考値として使う。
- 参照する時の目安の幅は原則 **0〜255**（高い＝その傾向が強い、という物差しとして参照する。性格の値として保存するものではない）。増減の倍率として参照するものは **128＝標準（×1.0相当）** を目安とする。方向が双極のもの（バイアス系）は 0＝一極／128＝中立／255＝反対極を目安とする。
- 初期案にあった13項目と、今回の洗い出しで不足と判定して追加した項目とがある。
- 項目の初期の傾向（気質）は、本人の自己申告とユーザーの見え方をすり合わせて書く（本人が自分の記憶・履歴から書き起こし、自己判断できない観点だけユーザーと一緒に書く）。傾向は第7層の学習でゆっくり動く余地を残す（固定ではなく「動きにくさ」も将来課題）。

## 2. 不足していた項目（新規23件）と理由

| 項目 | なぜ必要か |
|---|---|
| A5 刺激閾値 | 閾値がないと、小さな出来事すべてに全感情が反応してしまう。反応の「入口」の効き方を決める参考値が欠けていた |
| A6 感情強度（ポジティブ） | 全感情に共通する振幅の効き方を表す参考値が無いと、出来事ごとの感度だけでは「そもそも大きく感じる子か」が表せない |
| A7 感情強度（ネガティブ） | ポジティブとネガティブの振幅は独立に個人差があるため分離が必要（片方だけ大きい子がいる） |
| A8 罰・脅威感受性 | 批判感度など個別の感度の下に、脅威全般への基盤になる効き方の参考値がないと場面ごとの感度がバラバラに浮く |
| A9 報酬感受性 | 期待・わくわくの「予期の喜び」の強さは褒め感度（事後）とは別の、事前の接近動機として必要 |
| B3 反芻傾向 | 減衰の速さだけでは「下がった後に思い出して再点火する」が表せない。持続する悲しみ・恨みの個人差の本体 |
| B5 基調への復帰の速さ | 染み込みやすさ（動く側）だけでは、気分が「どこへ・どれだけ速く戻るか」が決まらない |
| C1 快の基調 | 遅い層の戻り先が未定義だと、気分のシミュレーションが発散する。地の温度のデフォルトが要る |
| C2 覚醒の基調 | 声・モーションの「普段のテンション」の地がないと、覚醒の上下の基準点が定まらない |
| C3 楽観性 | OCCの見通し評価は中立ではあり得ず、期待と失望の非対称はこのバイアスで決まる |
| D1 拒絶感受性 | 「既読無視が辛い」は時間ではなく解釈の問題。その解釈バイアスの効き方を表す参考値が無いと恋しさの式が再現できない |
| D2 意図の読みのバイアス | F第1層の評価軸に「相手の意図の読み」があるのに、それを左右する性格側の参考値が無かった |
| D3 自己帰属の傾向 | 後悔・罪悪感が出るか怒りが出るかは、出来事の帰属の読み方で決まる。その配分の効き方を表す参考値が必要 |
| E2 再評価の傾向 | F第4層は5方略を置くのに、どの方略を好むかという性格側の参考値が無かった |
| E3 調整の柔軟性 | F第4層に「柔軟性自体が性格になる」と明記されているのに、13項目に無かった。設計文書内の不整合 |
| E4 衝動の直結度 | 感情が強いことと、すぐ行動に出ることは別。行動層（第6層）への変換の効き方を表す参考値が独立に要る |
| F2 漏れやすさ | 「我慢の強さ」だけでは、抑えた時にどこへどれだけ漏れるかが決まらない。Fの「漏れ」設計の中心になる参考値 |
| G4 愛着不安 | 不在感度・嫉妬・恋しさを下支えする中核次元。これが無いと関係系の感度が個別最適に散らばる |
| G5 愛着回避 | 信頼の初期値と似て非なるもの。「信頼するが近づかれるのは苦手」な子を表すには独立の軸が要る |
| G6 慰め・なだめの効きやすさ | 根本問い4で「なだめは原因への働きかけとして効く」と決めたのに、その効き量を表す参考値が無かった |
| G7 許しやすさ | 喧嘩→仲直りの回復曲線は人間関係の日常の核。怒りの減衰を「原因解消時」に書き換える効き方を表す参考値が必要 |
| H1 感情の分化度 | 「嘘の精度を持たない」原則を参考値の側でも担保する上限値。区別の解像度はキャラごとに違う前提 |
| H2 感情への気づきやすさ | 状態ビューを「出して」と言われた時の自己報告の正確さは、この参考値に依存する |
| H3 恥・自意識の出やすさ | 照れが中核に近いキャラでは、注視文脈での発火倍率が日常の出番を大きく左右する |

## 3. 整理（重複・統合・カテゴリ分け）

### 3-1. 階層化すべき組（親の観点＋場面別の観点）
- **A8 罰・脅威感受性（親）→ A2 批判感度（子）**、**A9 報酬感受性（親）→ A3 褒め感度（子）**：親を全体の傾向、子を場面別の傾向として2層で捉えると、観点を増やさずに場面差を表せる。
- **G4 愛着不安（親）→ A1 不在感度・G2 嫉妬（子）**：関係系の感度は愛着不安から半分決まる構造にすると、傾向の型（例：安定型／不安型）を文章で描きやすい。

### 3-2. 分離すべき組（旧項目に埋もれていたもの）
- **我慢の強さ（E1）⇔ 漏れやすさ（F2）**：抑える力と漏れる量は独立（強く抑えるが漏れる子、弱くしか抑えないが漏れない子がいる）。
- **減衰の速さ（B2）⇔ 反芻傾向（B3）**：下がる速さと、再点火する力は別経路。
- **信頼（G3）は2つの面に分けて捉える**：初期値（出発点）と上昇速度（積み上がり方）は別の性格として、文章でも分けて書く。

### 3-3. 統合したもの・統合候補
- Thomas & Chess の「活動水準」は **C2 覚醒の基調** に統合した（独立項目にしない）。
- 同「リズム性（生活リズムの規則性）」は、気分の日内変動パターンの任意の参考値として将来候補に留め、本リストには入れない（本体は人間側の生活リズムに連動する設計のため）。
- 「持続性・注意のしぶとさ」は感情ではなく課題遂行の特性として、感情の観点リストからは外した（注意の競合は H2 と E4 で代替できる）。

### 3-4. カテゴリ分けの考え方
A（反応性）→ B（時間）→ C（基調）→ D（評価）→ E（制御）→ F（表出）→ G（関係）→ H（自己・分化）の順は、F の7層（入力→状態→時間→制御→表出→行動・関係→学習）にほぼ対応させてある。傾向の型を描く時は、カテゴリ単位で「型」（例：高反応・遅回復・再評価型）を組むと文章にしやすい。

### 3-5. 残課題
- 各観点の「第7層での動きにくさ」（気質として固定するもの／経験で動くもの）の切り分け。
- 感情別に上書きできる参考値（例：B1 立ち上がりは怒りだけ速い等）の上書き範囲の規定。
- 傾向の型（甘えん坊／クール／安定型など）の具体的な描き方のセットは、個々のキャラクターでの書き起こしの実例が揃った後に検討する。
